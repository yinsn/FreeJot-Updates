# 释手 / FreeJot 安装与更新

Agent 安装主页：https://yinsn.github.io/FreeJot-Updates/

本仓库公开提供完整安装包、程序更新包、下载页面、安装文档和校验信息，无需 GitHub 账号。

## 新 Mac 首次安装

先读 [完整安装指南](https://yinsn.github.io/FreeJot-Updates/INSTALL.md) 或 [网页版](https://yinsn.github.io/FreeJot-Updates/install.html)。完整 0.2.4 安装包包含程序和两个模型，约 5.37 GB。直接从首页下载安装助手和全部三个分卷，按指南校验、合并和安装，不必先装旧版。四个附件均在本公开仓库的 v0.2.4 Release，可直接下载，无需登录或源码仓库权限。安装后在应用内检查更新到当前版本 **0.2.20**。

agent 入口：[llms.txt](https://yinsn.github.io/FreeJot-Updates/llms.txt) · [install.json](https://yinsn.github.io/FreeJot-Updates/install.json)。文档有分卷、完整 ZIP、全部模型和应用签名的验证方法，包括 `tokenizer.json` 缺失处理。只有系统权限确认且实际听写成功，才能报告安装可用。

## 已有完整离线版

使用公开的轻量更新包，复用本机模型。0.2.1 及更早版本需手动升级一次；完整 0.2.0 可直接升级到 0.2.20，无需逐版安装。0.2.2 及以后可在「设置 → 关于释手 → 检查更新」完成后续升级。

0.2.7 新增「运行时固定系统麦克风」，默认关闭。每台 Mac 更新后需选定本机话筒并开启；手动选择蓝牙话筒后可开启首字保护。

0.2.8 改善了应用内更新交接：退出期间短暂无法读取进程状态时会限时重试，持续无法确认退出时仍停止安装。

0.2.9 在固定麦克风时保留原来的声音播放设备，并增加「声音播放」选择。如果旧版本已把声音切到话筒，可在此重新选择耳机；输入与输出互相抢占时会暂停固定麦克风。MacBook Air 蓝牙连接大疆 Mic Mini 并同时使用蓝牙耳机的效果，仍需在目标机器上验证。

0.2.10 改进智能整理中的英文纠偏，结合个人词典和句意修正误识；所有模式最终都会补齐中英文之间的空格，包括规则整理和模型回退。

0.2.12 保留“一个、两个人、三次、两天”等日常小数量，已经识别成阿拉伯数字的小数量也会还原。日期、金额、编号、统计数值和百分比等继续用阿拉伯数字；所有模式生效，固定表达和含糊数量保留原说法。

0.2.13 修复部分离散声道输入在转成单声道时被错误映射为静音的问题；已有有效声道映射保持不变。录音诊断中增加输入声道数和峰值，便于区分无输入声音与识别问题。此问题已用合成音频复现并验证修复；尚未在 MacBook Air 内置麦克风上完成实机验证。

0.2.14 加强确认问句保护：智能整理必须保留“是吧、对吧、好吗、好么”和“吗、吧”等表达；若模型删除、增加或替换受保护表达，则回退到原文并执行基础清理。校验不依赖逗号或问号，也检查重复出现的确认表达。

0.2.20 提速英语听写：录音开始后提前准备英语模型，连续听写复用模型和固定提示词，中英文切换也可复用各自缓存。32 GB 机器空闲最多保留 2 分钟，内存紧张或电脑睡眠时释放临时模型。模型与精度保持不变；延续 Option 标准英语和 0.2.19 的 UU 粘贴等待。

0.2.19 增加 UU 远程粘贴兼容：本机释手向 UU 远程窗口输入时，先更新本机剪贴板，默认等待 1 秒后只发送一次粘贴，为远端同步留出时间，减少第一次粘贴仍是上一句的问题。「设置 → 快捷键 → UU 远程输入」可选择关闭或等待 0.5–3 秒；其他应用不增加同步等待。等待期间按 Esc 可取消，操作键鼠、切换目标窗口或剪贴板被改写时停止自动粘贴。内容仍可从历史记录复制。等待是兼容措施，不能确认远端已完成同步，较慢网络可增加等待时间。此模式用于释手运行在控制端的情况。

0.2.18 新增英语听写：默认单按 Option 开始、再按一下结束，将中文、英文或中英混合整理成标准英语。左右 Option 均可；组合键和配合鼠标点击不触发。原普通快捷键与整理模式保留；若普通听写已占用一个 Option，则另一个用于英语。可在「设置 → 快捷键」关闭。英语转换复用本机模型，规则模式临时加载，用完释放；失败保留原文并提示，不粘贴中文回退。

0.2.17 修复蓝牙麦克风与扬声器采样率不同时的录音启动问题。选择麦克风后按设备的实际输入格式录音，再转换为识别所需的音频；无需手动调整系统播放设备或音频采样率。原有模型、词典、历史、快捷键和开头保护设置继续保留。

0.2.16 改善 Claude 桌面端 Code 输入框的兼容性：通过原生粘贴菜单输入，避免重复派发粘贴；无法确认调用结果时不自动重试。空输入框上报占位长度时，核实实际编辑范围为空后再建立连续听写的位置记录，以便下一句补回前一句标点。判断仍在本机完成，不增加模型调用。

0.2.15 取消固定追加末尾空格：空输入框只写入正文，末尾不留句末标点或空格。继续在同一输入框末尾听写时，核对光标前的短文本、光标位置和文本长度；匹配上一段听写的插入位置后，在两段之间补回上一段原有的标点，疑问句沿用原来的问号。已有标点或换行不重复补；手打前文、位置不匹配、选区替换、正文中间插入或读取失败时保守跳过。新一段末尾仍不补标点或空格，内部标点与中英文间距保留。此功能不增加模型调用，也不把输入框内容加入提示词。

应用读取 `app-update.json` 获取最新正式版本。语音识别与文字整理仍在本机进行；检查和下载更新仅在用户主动操作时发生。

页面和文档源文件由主项目的 `Resources/Updates/` 维护；分发仓库只保存公开文件，不包含应用源码或用户数据。
