# 释手 / FreeJot 安装与更新

Agent 安装主页：https://yinsn.github.io/FreeJot-Updates/

本仓库公开提供完整安装包、程序更新包、下载页面、安装文档和校验信息，无需 GitHub 账号。

## 新 Mac 首次安装

先读 [完整安装指南](https://yinsn.github.io/FreeJot-Updates/INSTALL.md) 或 [网页版](https://yinsn.github.io/FreeJot-Updates/install.html)。完整 0.2.4 安装包包含程序和两个模型，约 5.37 GB。直接从首页下载安装助手和全部三个分卷，按指南校验、合并和安装，不必先装旧版。四个附件均在本公开仓库的 v0.2.4 Release，可直接下载，无需登录或源码仓库权限。安装后在应用内检查更新到当前版本 **0.4.7**。

agent 入口：[llms.txt](https://yinsn.github.io/FreeJot-Updates/llms.txt) · [install.json](https://yinsn.github.io/FreeJot-Updates/install.json)。文档有分卷、完整 ZIP、全部模型和应用签名的验证方法，包括 `tokenizer.json` 缺失处理。只有系统权限确认且实际听写成功，才能报告安装可用。

## 已有完整离线版

使用公开的轻量更新包，复用本机模型。0.2.1 及更早版本需手动升级一次；完整 0.2.0 可直接升级到 0.4.7，无需逐版安装。0.2.2 及以后可在「设置 → 关于释手 → 检查更新」完成后续升级。

「运行时固定系统麦克风」默认关闭，每台 Mac 单独开启。当前版本在自动模式下也支持蓝牙与 Bluetooth LE 外接输入；如需始终使用某个独立话筒，可手动指定并开启固定。蓝牙同样遵循「保护第一个字」开关。

0.2.8 改善了应用内更新交接：退出期间短暂无法读取进程状态时会限时重试，持续无法确认退出时仍停止安装。

0.2.9 在固定麦克风时保留原来的声音播放设备，并增加「声音播放」选择。如果旧版本已把声音切到话筒，可在此重新选择耳机；输入与输出互相抢占时会暂停固定麦克风。MacBook Air 蓝牙连接大疆 Mic Mini 并同时使用蓝牙耳机的效果，仍需在目标机器上验证。

0.2.10 改进智能整理中的英文纠偏，结合个人词典和句意修正误识；所有模式最终都会补齐中英文之间的空格，包括规则整理和模型回退。

0.2.12 保留“一个、两个人、三次、两天”等日常小数量，已经识别成阿拉伯数字的小数量也会还原。日期、金额、编号、统计数值和百分比等继续用阿拉伯数字；所有模式生效，固定表达和含糊数量保留原说法。

0.2.13 修复部分离散声道输入在转成单声道时被错误映射为静音的问题；已有有效声道映射保持不变。录音诊断中增加输入声道数和峰值，便于区分无输入声音与识别问题。此问题已用合成音频复现并验证修复；尚未在 MacBook Air 内置麦克风上完成实机验证。

0.2.14 加强确认问句保护：智能整理必须保留“是吧、对吧、好吗、好么”和“吗、吧”等表达；若模型删除、增加或替换受保护表达，则回退到原文并执行基础清理。校验不依赖逗号或问号，也检查重复出现的确认表达。

0.4.7 调整上屏时机：录音期间可以点击、按键或切换输入位置，按下结束键时才确定当前输入框；录音期间的操作不再直接取消自动上屏。结束后若又操作键鼠、切换目标或无法确认位置，则保留文字，并显示约 3 秒、不抢焦点的可见提示。微信和 Codex 沿用 0.4.6 的通用原生粘贴与完整快捷键回退，模型和 F16 用法沿用。

0.4.6 修正通用上屏链路：普通本机应用统一优先使用可确认的原生「粘贴」命令，覆盖 Codex 等应用；只有确认没有该命令时才回退键盘。键盘回退发送完整的 Command 按下、V 按下／松开、Command 松开序列，并定向投递到已核对的进程；合成事件有专用标记，不会误触发听写或回填保护。用户仍按住修饰键、菜单禁用、目标变化或动作未确认时保留文字，不重试。UU 沿用既有等待与 HID 投递方式，使用同样的完整快捷键序列。现有模型沿用。

0.4.5 改善微信上屏兼容：微信中直接调用原生「粘贴」命令，避开模拟 Command+V 只出现字母 V 的情况；菜单查找、目标核对与粘贴动作使用各自有界的时间预算，减少有效目标被误判超时。菜单不可用或动作未确认时保留文字，不重复派发按键。F16／脚踏板、录音流程及现有模型沿用。

0.4.4 完善听写输入与恢复：普通修饰键只响应独立短按，组合键和长按不再触发；录音开始记住原窗口和输入框，目标改变、录音后有其他键鼠操作或无法核对时只复制并提示，不抢回焦点。历史保存失败明确显示暂存状态并可重试，损坏文件先备份；新增停止并保留原文、历史搜索、删除撤销、重新整理和转英语，重处理结果供核对复制，不自动粘贴。英语转换增加数字、日期、版本、链接和明确币种检查，未通过时保留原文及候选译文。设置新增权限自检、模型下载进度和输入法词库维护，分别显示内置与个人词库，可添加短语、忘记学习、屏蔽或恢复候选；听写词条添加失败保留输入。继续复用现有模型。

0.4.3 加强语音听写首尾保护：开启「保护第一个字」时，按键前的内存缓冲从 300 毫秒增至 600 毫秒；停止键后继续收取 250 毫秒真实尾音，减少提前开口或说完尾字时按键造成的截断。智能整理也会拒绝仅删除首尾真实内容的结果并回退到原文。收尾通常增加约四分之一秒；沿用已有模型。

0.4.2 将蓝牙（含 Bluetooth LE）与 USB 等受支持的外接麦克风纳入同一自动优先级：先选可用外接输入，再回退本机内置输入；多个外接输入可用时优先系统当前默认输入。开启「运行时固定系统麦克风」后，已选外接话筒保持到断开；自动模式在设备断开时重新选择，当前回退到内置时，外接话筒重连就绪后重新优先使用；已固定且仍连接的其他外接话筒继续保留。蓝牙连接较晚才就绪时也会刷新待机设备，避免继续沿用内置麦克风。手动指定设备断开时仍明确报错，不自动替换；有线话筒的声音播放保护沿用 0.4.1。继续复用已有模型。

0.4.1（此前版本）改善 USB 等有线外接麦克风误带走外放的问题：持续保护最近已知、仍可用的独立扬声器或耳机，即使关闭「运行时固定系统麦克风」也生效。可随时在「声音播放」重新选择播放设备；若启动时已是错误输出且没有先前记录，需要明确选择一次。用户在这里明确选择话筒监听时保留该选择。自动选择仍优先有线外接话筒，再回退本机设备，并修复先以内置麦克风启动、随后接入外接话筒时系统固定未跟随的问题；该版本的蓝牙输入仍需手动选择。本机验证使用 PD400X USB 麦克风，目标大疆接收器尚未实机复测。继续复用已有模型。

0.4.0 修复了从搜狗导入的个人词库排序问题（此前把搜狗内部权重当词频，少数常用拼音首选是生僻词），并新增可选功能：装了搜狗的 Mac 可让释手读取本机搜狗系统词库、换算成本地词频表叠加，使候选更接近搜狗；该表只在本机与你自选的同步文件夹，不随更新包分发，没装搜狗无变化。继续复用已有模型。

0.3.8 为释手拼音内置约 28 万条通用词库，没导入搜狗词库也能打出常用词和整句；新增上下文选词，按刚上屏的最近几个词给同音候选重新排序，上下文只留在当前输入会话的内存里，不写盘、不同步。搭配统计来自 Tatoeba、Global Voices 与中文维基百科，维基百科统计表按 CC BY-SA 4.0 随 Release 单独提供。修复组字时按快捷键后空格提交过期首选的问题。继续复用已有模型。

0.3.7 加强短音节漏打和换位纠错，并增加独立的本机选词次数与最近选择排序；低频同音词可按个人习惯提前，重启后保留。改进简拼与全拼跨词组句，继续复用已有模型。个人选择序号仅在本机保存，词条仍沿用原有跨 Mac 同步。

0.3.6 新增拼音误拼纠错：漏打、多打、替换或相邻字母换位一处时，可以选择正确中文，例如 nihoa →「你好」、wmoen →「我们」、zhogn →「中」。完整纠错候选排在部分候选、简拼和自动英文拼接之前；正常精确输入保持原有顺序。本版只增加拼音纠错，沿用现有学习与同步方式。

0.3.5 加强 Shift 轻按识别，修复事件回归测试复现的提前切换路径；问号、大写字母及组合键的回归测试已通过，实际键盘体验待反馈。系统输入法名称统一为「释手」。选词会自动增加词频并逐步调整排序；两台 Mac 开启词典同步、选择同一 iCloud Drive 文件夹并保持释手主程序运行后，学习词频可跨机器同步。同步按分钟检查，iCloud 到达时间由系统决定。

0.3.4 修复 0.3.3 的释手拼音切换后只出英文、候选框不显示和位置靠边的问题：输入法现在能正确接收按键并组字，候选框跟随光标显示。已经把释手拼音加入输入法列表的 Mac，用应用内更新升级到 0.3.4 即可；还没加入的，按释手的提示在系统设置里添加一次。

0.3.3 修复更新后释手拼音没有装上、系统输入法列表里找不到的问题：更新后释手会在空闲时自动把释手拼音装进系统。macOS 只允许用户自己把输入法加入输入法列表，所以还需要按释手的提示添加一次：打开「系统设置 → 键盘」，在「文字输入 › 输入法」点「编辑…」，点「+」，选「简体中文」→「释手拼音」→「添加」。添加过的 Mac 以后更新会自动升级。0.3.2 可直接用应用内更新升级。

0.3.2 修复 0.3.1 在 macOS 26 上启动几秒即闪退、以及输入法未出现在输入法列表的问题：安装器改为在主线程注册与启用释手拼音，首次启用被打断时下次启动会补完。0.3.1 启动即闪退的 Mac 无法用应用内更新，请下载本版轻量更新包，退出释手后运行包内的「释手更新器」选择 /Applications/FreeJot.app 升级。

0.3.1 起释手拼音随释手一起安装与升级：更新后释手在空闲时自动安装并注册输入法，首次安装启用、以后升级保留你的启用选择；输入法词库经「词典同步」所选的 iCloud Drive 文件夹在多台 Mac 间同步，装有搜狗的 Mac 自动导入本机搜狗个人词库，学习词、短语与屏蔽词的增删都会同步。

0.3.0 新增「释手拼音」输入法：独立的 macOS 原生拼音输入法，全拼/简拼/整句、部分选词、中英文混合输入、中文标点、学习与屏蔽词；候选窗参考搜狗默认外观；词库从本机搜狗个人词库导出为可手工维护的纯文本，不上传、不进安装包；输入法全程本地无网络。它作为单独的 `FreeJotInput-0.3.0-AppleSilicon.zip` 发布，需手动放入 `~/Library/Input Methods/` 并在系统设置里添加；听写主程序本次只更新版本号。

0.2.25 修复 USB 麦克风误带走声音输出的问题：启用「运行时固定系统麦克风」时，输入切换和录音开启期间保留原来的扬声器或耳机，兼顾系统提示音；输出指向没有播放声道的麦克风时也能恢复。用户主动选择新的播放设备仍会被保留。重新插入接收器或从睡眠恢复时，会尝试恢复已记录且仍可用的独立播放设备；系统连续抢切时暂停固定并提示。缺少可恢复的原播放选择，或旧版已留下错误输出时，启用「运行时固定系统麦克风」后可在「声音播放」重新选择 Mac 自带扬声器；未启用时在 macOS「系统设置 → 声音 → 输出」选回。

0.2.24 缩短短句识别等待：录音期间每约 2 秒准备一份草稿，停止后用完整录音核对，允许纠正前文和句尾；缩小音频回调请求，最后一段音频到齐后立即继续处理。普通听写与右 Option 英语听写均生效，无需额外设置。沿用现有模型、精度和长录音分段方案；实际收益取决于句长、机器负载和音频设备。

0.2.23 提速长录音：录音达到约 33 秒后，开始提前识别切分位置已稳定的前段；结束录音时复用已完成的识别，只处理剩余内容，再对全文进行一次整理或英语转换，并一次性输入。沿用原有模型、精度与分段规则；短句沿用原有识别流程，右 Option 英语入口和 UU 远程粘贴等待保留。

0.2.22 将英语听写快捷键改为仅右侧 Option：单独按下并松开开始，再按一下结束，左 Option 不触发英语翻译。普通听写快捷键与已保存的英语开关保留；若普通听写已占用右 Option，则提示更换普通快捷键，英语入口不再改用左侧。

0.2.21 加快简体中文的智能整理：批量验证与原文相同的文字，减少逐字计算，仍由原模型逐个确认输出。纯英文、繁体中文和过短文本沿用原有路径。模型、精度、提示词、词典和输出保护保持不变；语音识别阶段与规则整理不变。

0.2.20 提速英语听写：录音开始后提前准备英语模型，连续听写复用模型和固定提示词，中英文切换也可复用各自缓存。32 GB 机器空闲最多保留 2 分钟，内存紧张或电脑睡眠时释放临时模型。模型与精度保持不变；延续 Option 标准英语和 0.2.19 的 UU 粘贴等待。

0.2.19 增加 UU 远程粘贴兼容：本机释手向 UU 远程窗口输入时，先更新本机剪贴板，默认等待 1 秒后只发送一次粘贴，为远端同步留出时间，减少第一次粘贴仍是上一句的问题。「设置 → 快捷键 → UU 远程输入」可选择关闭或等待 0.5–3 秒；其他应用不增加同步等待。等待期间按 Esc 可取消，操作键鼠、切换目标窗口或剪贴板被改写时停止自动粘贴。内容仍可从历史记录复制。等待是兼容措施，不能确认远端已完成同步，较慢网络可增加等待时间。此模式用于释手运行在控制端的情况。

0.2.18 新增英语听写，将中文、英文或中英混合整理成标准英语。0.2.22 起仅单按右 Option 开始、再按一下结束；组合键和配合鼠标点击不触发。原普通快捷键与整理模式保留。可在「设置 → 快捷键」关闭。英语转换复用本机模型，规则模式临时加载，用完释放；失败保留原文并提示，不粘贴中文回退。

0.2.17 修复蓝牙麦克风与扬声器采样率不同时的录音启动问题。选择麦克风后按设备的实际输入格式录音，再转换为识别所需的音频；无需手动调整系统播放设备或音频采样率。原有模型、词典、历史、快捷键和开头保护设置继续保留。

0.2.16 改善 Claude 桌面端 Code 输入框的兼容性：通过原生粘贴菜单输入，避免重复派发粘贴；无法确认调用结果时不自动重试。空输入框上报占位长度时，核实实际编辑范围为空后再建立连续听写的位置记录，以便下一句补回前一句标点。判断仍在本机完成，不增加模型调用。

0.2.15 取消固定追加末尾空格：空输入框只写入正文，末尾不留句末标点或空格。继续在同一输入框末尾听写时，核对光标前的短文本、光标位置和文本长度；匹配上一段听写的插入位置后，在两段之间补回上一段原有的标点，疑问句沿用原来的问号。已有标点或换行不重复补；手打前文、位置不匹配、选区替换、正文中间插入或读取失败时保守跳过。新一段末尾仍不补标点或空格，内部标点与中英文间距保留。此功能不增加模型调用，也不把输入框内容加入提示词。

应用读取 `app-update.json` 获取最新正式版本。语音识别与文字整理仍在本机进行；检查和下载更新仅在用户主动操作时发生。

页面和文档源文件由主项目的 `Resources/Updates/` 维护；分发仓库只保存公开文件，不包含应用源码或用户数据。
